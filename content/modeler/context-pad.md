The **Context Pad** is one of the main ways to interact with the diagram in CadenzaFlow Modeler. It allows you to perform operations on the selected element or append new elements to it.

## Interacation

Actions that change the selected element can be found in the context pad appearing around the selected element, while actions that append or attach new elements are typically accessible through the icons.

### Append Elements

The **Append** feature allows you to append any element directly without having to drag and drop from the palette. Click on the context pad icons to append tasks, gateways, or events connected by a sequence flow.

### Attach Boundary Events

The **Attach** feature lets you attach boundary events to activities with a single click.

### Link Resources

Linking resources like other BPMN diagrams, DMN tables, or Forms can also be configured through the properties panel, but the context pad provides quick access to common actions.

### Comments

You can add documentation or comments to elements to facilitate collaboration.

## Key Actions

| Icon | Action | Description |
|---|---|---|
| <i class="fa fa-trash"></i> | **Remove** | Deletes the selected element. |
| <i class="fa fa-arrows"></i> | **Connect** | Starts a connection tool to link to another element. |
| <i class="fa fa-cog"></i> | **Change Type** | Changes the type of the element (e.g., from Task to User Task). |
| <i class="fa fa-font"></i> | **Add Text** | Adds a text annotation. |

*Note: The available actions depend on the selected element type.*
