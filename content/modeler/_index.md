CadenzaFlow Modeler is a desktop application for modeling BPMN and DMN. It allows you to model files located directly on your local file system.

{{< img src="img/cadenzaflow-modeler.png" title="CadenzaFlow Modeler" >}}

This is a guide to get you started with modeling BPMN diagrams and DMN decision tables. Make sure to [Install the CadenzaFlow Modeler]({{< ref "/installation/cadenzaflow-modeler.md" >}}) first.
